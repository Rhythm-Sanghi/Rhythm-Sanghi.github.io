A decision behind the tool+

Keep the analysis in Rust.

The desktop app and CLI share one engine. React asks for bounded graph slices instead of parsing or traversing the whole repository. The result stays local, and the interface can concentrate on the part of the code you’re looking at.

Benchlight

Early Windows release · v0.1.0 WORKSPACE UTILITY

A closer look at the space
around your projects.

See where disk space goes, which tools your PATH resolves, and what changed since a project last worked. Review the evidence before cleaning anything up.

Read case study ↗Download for Windows ↗
Built with
Rust · Tauri · React · SQLite
Release
9 Oct 2026 · Source ↗
Runs on
Windows desktop + CLI
A decision behind the tool+

Measurement comes before cleanup.

Generated doesn’t always mean disposable. Benchlight separates rebuildable files from items that need review, keeps partial measurements visible, and requires confirmation before eligible directories are recycled. Logical size is never presented as a promise of recovered space.
